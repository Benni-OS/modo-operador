## 🎯 O Que é o Modo Operador?

O **Modo Operador** é a formação técnica e manual prático de engenharia voltado a desenvolvedores, fundadores técnicos e arquitetos de software que querem dominar a construção de **sistemas de agentes autônomos soberanos**.

Enquanto o mercado ensina truques superficiais de prompt para interfaces de chat, o Modo Operador ensina a **camada de infraestrutura**:
- Protocolos de ferramentas nativas via **Model Context Protocol (FastMCP)**.
- Runtimes locais soberanos com **Ollama** e roteamento com failover (Groq / Anthropic / OpenAI).
- Formações de multiagentes com **Run Ledger imutável**, validação por **Reality Lock** e orquestração dirigida a eventos.
- Como transformar essa infraestrutura em **serviços corporativos de alto valor (R$ 5.000 a R$ 25.000)** e produtos autônomos escaláveis.

Tudo é fundamentado em um **arsenal com mais de 10 ferramentas públicas e open source** mantidas no GitHub pela comunidade.

Todo o ecossistema é baseado em software livre e código real que você pode auditar, clonar, testar e utilizar em produção comercial:

| Repositório | Descrição Técnica | Licença | Status |
|---|---|---|---|
| [**`mcp-forge`**](https://github.com/modo-operador/mcp-forge) | Framework declarativo estilo FastAPI para construção ultrarrápida de servidores MCP em Python com auto-schema e tipagem estrita. | `MIT` | 🟢 Ativo |
| [**`operator-nexus`**](https://github.com/modo-operador/operator-nexus) | Gateway inteligente de inferência LLM — unifica Ollama local, Groq, OpenAI e Claude em endpoint único compatível com OpenAI, roteamento por estratégia e failover automático. | `MIT` | 🟢 Ativo |

## 🎁 Bônus e Ferramental Incluso

- **Template de Pipeline CI/CD para Agentes:** Configurações completas de GitHub Actions + Docker para empacotamento, testes e deploy de agentes em VPS ou bare-metal.
- **Planilha de Custos Operacionais e Token Economics:** Modelo financeiro para calcular viabilidade, unit economics de chamadas LLM e ROI de infraestrutura local vs cloud.
- **4 Specs Operacionais Prontos para Produção:**
  - 🧱 `Scaffold`: Setup de ambiente, CI, tipagem estrita e testes base.
  - ✨ `Feature`: Desenvolvimento BDD, validação cruzada e cobertura > 80%.
  - 🔨 `Refactor`: Otimização com testes de regressão automatizados.
  - 🚀 `Deploy`: Healthcheck, gates de aprovação e rollback automatizado.

## 🛠️ Stack Tecnológica

- **Linguagens:** Python 3.11+, TypeScript, Node.js, Shell / Bash.
- **Runtimes & Modelos:** Ollama (Llama 3, DeepSeek, Qwen), Groq, OpenAI, Anthropic via `operator-nexus`.
- **Protocolos:** Model Context Protocol (FastMCP), JSON-RPC 2.0, Webhooks assíncronos.
- **Governança & Auditoria:** Run Ledger imutável, Reality Lock, Approval Gates determinísticos.
- **Infraestrutura:** Docker, Compose, Linux VPS / Bare Metal, GitHub Actions.
